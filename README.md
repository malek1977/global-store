# 🌍 Global Store — جلوبال ستور

منصة متكاملة لإدارة محل جوالات وإكسسوارات: **متجر تفاعلي** للبيع والشراء + **نظام محاسبي بالقيد المزدوج** + **لوحة إدارة** للمخزون والصيانة والموظفين، بواجهة عربية/إنجليزية كاملة (RTL/LTR).

> 🔗 **النسخة المنشورة (تجريبية):** https://u3kjnzycrhqvc.space.minimax.io

---

## ⚡ التشغيل السريع

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production bundle → dist/
npm test           # 5 اختبارات آلية
```

| المستخدم | الدور |
|---------|-------|
| `admin` | مدير عام — كل الصلاحيات |

## 🧩 المميزات

### 🛒 المتجر
كتالوج منتجات مع تصنيفات وفلترة، صفحات منتج، سلة، **checkout**، تأكيد طلب، و**تتبّع الطلب** برقمه.
صفحة حجز صيانة أونلاين.

### 📊 النظام المحاسبي (قيد مزدوج)
مولّد قيود تلقائي لكل عملية (بيع/شراء/دفع/مصروف) — **كل قيد متوازن تلقائياً**.
- دفتر اليومية (Journal)
- دفتر الأستاذ (Ledger)
- ميزان المراجعة (Trial Balance)
- الميزانية العمومية (Balance Sheet)
- ضريبة القيمة المضافة (VAT)
- كشوف الحساب (Statements)
- سندات القبض والصرف

### 📦 الإدارة
مخزون مع **حركة مخزون** لكل صنف، مشتريات، موردون وعملاء، صيانة وتشخيص ذكي، موظفون، إعدادات.

### 🤖 الذكاء الاصطناعي
مساعد مدمج: تحليل تشخيص أعطال الأجهزة، اقتراحات، وتنبيهات المخزون.

### 🌍 i18n
عربي + إنجليزي كامل مع دعم **RTL/LTR**، تبديل فوري بلا إعادة تحميل.

## 🏗️ البنية

```
src/
  db/            مخطط SQLite + طبقة البيانات (sql.js) + البيانات التجريبية
  accounting/    محرّك القيد المزدوج
  ops/           منطق البيع والشراء والصيانة
  ai/            محرّك الذكاء الاصطناعي
  app/           الحالة العامة (State) + RequireAuth
  layouts/       تخطيط المتجر ولوحة الإدارة
  pages/         store/ · admin/ · accounting/ · ai/
  ui/            مكوّنات مشتركة
  i18n/          الترجمات

server/          API آمن (Express)
  src/           المسارات · المصادقة · RBAC · التحقق
  SECURITY.md    وثيقة الأمان
  render.yaml    نشر على Render
```

**نموذج التشغيل:** الواجهة تعمل **مستقلة** عبر `sql.js` داخل IndexedDB — بدون خادم.
وفي نفس الوقت `server/` فيه API آمن كامل (JWT + httpOnly cookies، RBAC، CSRF، rate limiting، Helmet/CSP، Zod، سجل تدقيق) جاهز للإنتاج.

## 🛡️ الأمان

- مصادقة JWT داخل **httpOnly cookies** (لا `localStorage`)
- **CSRF** double-submit token على كل طلب يغيّر البيانات
- **RBAC** — 6 أدوار بصلاحيات دقيقة
- **Rate limiting** على المسارات الحساسة
- **Helmet + CSP** صارمة
- تحقق من كل المدخلات بـ **Zod**
- **سجل تدقيق** لكل عملية حساسة
- تشفير كلمات المرور بـ `scrypt`

التفاصيل الكاملة في [`server/SECURITY.md`](server/SECURITY.md).

## 🧪 الاختبارات

البناء الناجح **لا يعني** إن التطبيق يشتغل — عشان كذا فيه اختبارات تشغّل الـ bundle فعلياً:

```bash
npm test
```

|---------|-------|

| `test-login.mjs` | تسجيل الدخول الحقيقي يوصل للوحة التحكم |

> كل اختبار من هذي كشف خطأ حقيقي فعلي في التطوير. لا تحذفها 😄
